# 03. Opérationnel et réglementaire : location courte durée, longue durée, due diligence, achat

Recherche réalisée le 19 octobre 2026. Sources françaises 2025-2026 privilégiées. Chaque fait numéroté renvoie à une URL. Les chiffres marqués (hypothèse) sont des ordres de grandeur de praticiens non sourcés par une étude unique : à calibrer sur le terrain.

Avertissement de méthode : les données de taux d'occupation varient fortement selon la source (AirDNA et Airbtics ne comptent pas les mêmes annonces : "annonces actives" vs "annonces réservées"). Les valeurs retenues pour le modèle (dernière section) sont volontairement prudentes.

## 1. Réglementation courte durée 2025-2026 (loi Le Meur et règlements locaux)

### 1.1 Cadre national : loi n° 2024-1039 du 19 novembre 2024 ("loi Le Meur")

1. Numéro d'enregistrement généralisé à toutes les communes (résidence principale ou non) au plus tard le 20 mai 2026 ; la déclaration passe par un téléservice national dont l'ouverture est annoncée par la DGE pour le 4e trimestre 2026. Dans l'intervalle, l'enregistrement se fait en mairie là où il existait déjà. Sources : https://www.cpim.fr/numero-enregistrement-meuble-tourisme-2026/ ; https://www.service-public.gouv.fr/particuliers/actualites/A18880?lang=fr ; https://www.empruntis.com/financement/actualites/2026/location-touristique-nouvelles-regles-21179/
2. Le numéro (13 caractères) doit figurer sur l'annonce ; les plateformes retirent les annonces sans numéro valide. Source : https://ulysse.com/news/annecy-airbnb-quotas-loi-le-meur-ete-2026
3. Amendes administratives et civiles : 10 000 € par défaut d'enregistrement ; 20 000 € pour fausse déclaration ou faux numéro ; 15 000 € pour dépassement du plafond 120/90 jours ; jusqu'à 100 000 € par local pour changement d'usage sans autorisation (art. L.651-2 CCH, amende civile) ; 100 €/jour de retard pour non-présentation d'un DPE valide et jusqu'à 5 000 € pour non-conformité énergétique. Sources : https://anil.org/parole-expert-logement-location/location-touristique-nouvelles-regles-2025 ; https://www.monmeublesaisonnier.com/blog/location-courte-duree-france-regles-ville ; https://www.cpim.fr/airbnb-reglementation/la-rochelle/
4. Résidence principale : plafond légal 120 nuits/an, que chaque commune peut abaisser à 90 nuits par délibération. Ont abaissé à 90 : Paris (depuis janvier 2025), Lyon (1er janvier 2026), Marseille, Bordeaux, Nice, Montpellier. Restent à 120 (au moment de la source) : Biarritz, Annecy, Strasbourg. Sources : https://www.monmeublesaisonnier.com/blog/location-courte-duree-france-regles-ville ; https://www.barnes-lyon.com/en/news/real-estate-market-1/limitation-to-90-days-for-tourist-rentals-of-primary-residences-in-lyon-starting-in-2026-971 ; https://www.cpim.fr/airbnb-reforme-2026-impact-investisseur/
5. Changement d'usage : toutes les communes (plus seulement celles de plus de 200 000 habitants et zones tendues) peuvent désormais soumettre la location touristique d'un logement à autorisation préalable, et fixer une proportion maximale de résidences principales pouvant obtenir une autorisation temporaire (quotas). Source : https://www.jedeclaremonmeuble.com/loi-le-meur-location-saisonniere-fiscalite/ ; https://www.actu-juridique.fr/fiscalite/fiscal-finances/airbnb-nouveau-revers-pour-la-ville-de-paris-la-loi-le-meur-nest-pas-retroactive/
6. DPE des meublés de tourisme : tout nouveau meublé soumis à autorisation de changement d'usage doit être classé A à E depuis le 21 novembre 2024 (F et G exclus) ; au 1er janvier 2034, tous les meublés de tourisme (hors résidence principale) devront être classés A à D. Sources : https://www.guesty.com/fr/blog/dpe-obligations-location-saisonniere/ ; https://www.pap.fr/actualites/location-touristique-dpe-et-regles-plus-severes-en-2025-louer-va-devenir-plus-difficile/a25825 ; https://anil.org/parole-expert-logement-location/location-touristique-nouvelles-regles-2025
7. Copropriété : le règlement de copropriété comportant une clause d'habitation bourgeoise peut désormais être modifié à la majorité des deux tiers (art. 26, au lieu de l'unanimité) pour interdire les meublés de tourisme ; tout copropriétaire qui loue en meublé de tourisme doit en informer le syndic ; les nouveaux règlements doivent se prononcer explicitement sur l'autorisation ou non. Dispositif validé par le Conseil constitutionnel en 2026. Sources : https://www.labase-lextenso.fr/gazette-du-palais/2026-n18/location-meublee-touristique-en-copropriete-le-conseil-constitutionnel-valide-le-dispositif-issu-de-la-loi-le-meur-GPL491i5 ; https://www.bjavocat.com/2024/11/27/les-meubles-de-tourisme-en-copropriete-depuis-la-loi-dite-le-meure/?pdf=13081 ; https://www.gererseul.com/?p=25074
8. Fiscalité micro-BIC (revenus 2025 déclarés 2026) : meublé non classé abattement 30 % (plafond 15 000 €) ; meublé classé abattement 50 % (plafond 77 700 €). Au-delà, régime réel obligatoire. Impact estimé pour un profil "mass market" : baisse de rendement net de 25 à 30 %. Le classement Atout France (environ 350 €) permet de conserver l'abattement 50 %. Sources : https://www.cpim.fr/airbnb-reforme-2026-impact-investisseur/ ; https://anil.org/parole-expert-logement-location/location-touristique-nouvelles-regles-2025
9. Boîtes à clés interdites sur le domaine public à Paris, Lille, Annecy, Saint-Malo, Biarritz, Marseille, Besançon, Nice, Avignon, Wimereux : prévoir serrure connectée ou boîte en partie privative (avec accord copro). Source : https://www.thelocal.fr/20251003/airbnb-crackdown-the-french-towns-that-have-short-term-property-rental-restrictions
10. Taxe d'habitation sur les résidences secondaires (THRS) : majoration jusqu'à 60 % votable dans 3 689 communes en zone tendue ; 1 666 l'appliquent en 2026 (688 au taux de 60 %). Un meublé de tourisme qui n'est pas la résidence principale y est en principe soumis (sauf cas de CFE exclusive à vérifier avec l'expert-comptable). Sources : https://www.moneyvox.fr/impot/actualites/109875/residence-secondaire-la-majoration-a-60-de-la-taxe-habitation-2026-concerne-plus-de-communes ; https://www.impots.gouv.fr/sites/default/files/media/9_statistiques/data_colloc/analyse_fdl/2026/dgfip_deliberations_2026_thrs_com.pdf
11. Réforme Airbnb du 13 octobre 2026 : commission unique de 15,5 % à la charge de l'hôte dans tout l'EEE (contre environ 3 % hôte + 14 à 16 % voyageur avant). S'applique à la nuitée, aux frais de ménage, animaux et voyageurs supplémentaires, pas aux taxes. Sources : https://www.hostfully.com/fr/blog/frais-dhote-airbnb-explication-des-frais-de-155-a-la-charge-exclusive-de-lhote-2026/ ; https://www.meilleurtaux.com/credit-immobilier/actualites/2026-octobre/airbnb-frais-uniques-des-le-13-octobre-2026.html ; https://hospitality-on.com/fr/location-meublee/airbnb-fait-desormais-payer-plus-de-15-de-frais-aux-hotes-contre-3-auparavant

### 1.2 Règlements locaux : villes quasi fermées vs permissives (résidence secondaire / investisseur)

12. Paris : 90 jours RP ; résidence secondaire soumise à changement d'usage avec compensation (transformation d'un local non résidentiel en logement, m² pour m², double dans certaines zones ; achat de "commercialité" très coûteux) ; taxe de séjour non classé plafonnée à 15,93 €/pers/nuit en 2026 ; la Ville applique aussi l'autorisation à la transformation de locaux commerciaux en hébergement touristique. Verdict : quasi impossible pour un investisseur. Sources : https://www.monmeublesaisonnier.com/blog/location-courte-duree-france-regles-ville ; https://cdn.paris.fr/paris/2025/01/08/6-fiche-technique-paris-fr-les-locations-meublees-de-courte-duree-owl5.pdf ; https://ulysse.com/news/paris-taxe-sejour-airbnb-2026-hausse
13. Lyon : 90 jours RP depuis le 1er janvier 2026 ; compensation obligatoire pour les résidences secondaires depuis le 1er juin 2022 dans l'hypercentre, et pour les logements de plus de 35 m² dans le reste de la ville ; autorisations limitées pour les petites surfaces hors hypercentre ; information du syndic obligatoire. Verdict : quasi impossible sauf petite surface hors hypercentre. Sources : https://www.lyon.fr/demarche/urbanisme/changement-dusage-dun-logement ; https://www.welkeys.com/pt/blog/durcissement-de-la-legislation-autour-des-locations-airbnb-a-lyon
14. Bordeaux : 90 jours RP ; résidence secondaire soumise à changement d'usage avec compensation (surface équivalente, même secteur) et quota très limité de logements par propriétaire ; nouveau règlement de changement d'usage adopté par Bordeaux Métropole le 26 septembre 2025. Verdict : quasi impossible. Sources : https://www.bordeaux-metropole.fr/sites/MET-BXMETRO-DRUPAL/files/bm_actes/organismes/bordeaux-metropole/conseils/2025-09-26/111081_Reglement%2520de%2520changement%2520dusage%2520-%25202025.pdf ; https://www.holidu.fr/magazine/regles-airbnb-bordeaux ; https://www.bordeaux.fr/location-touristique-bordeaux--guide-proprietaires
15. Marseille : 90 jours RP depuis 2025 ; compensation dès le premier bien en résidence secondaire (auparavant 1 résidence secondaire par période de 4 ans, et 5 avant 2021). Verdict : fermé aux investisseurs. Sources : https://madeinmarseille.net/168793-marseille-detaille-son-futur-reglement-airbnb-on-ne-pourra-louer-que-son-logement-principal/ ; https://www.echodumardi.com/actualite/marseille-nouveau-tour-de-vis-pour-les-locations-saisonnieres/?print=pdf
16. Nice : 90 jours RP ; autorisation temporaire de changement d'usage de 3 ans non renouvelable et non cessible pour les résidences secondaires, puis compensation ; quotas par zone (1,5 % des résidences principales ; 671 autorisations/an : 38 Vieux-Nice, 277 Riquier/Port/Mont-Boron, 298 centre-ville, 108 ouest). Le nouveau règlement a été suspendu en justice en 2026 : situation instable. Verdict : très contraint, incertain. Sources : https://www.lemondedudroit.fr/droit-civil/280-immobilier-construction/102938-meubles-touristiques-a-nice-le-nouveau-reglement-deja-suspendu.html ; https://www.monmeublesaisonnier.com/blog/location-courte-duree-france-regles-ville
17. Annecy : plafond de 2 660 meublés de tourisme à partir de juin 2026 (environ 3 740 annonces supprimées autour du lac). Verdict : fermé pour de nouveaux entrants. Source : https://ulysse.com/news/annecy-airbnb-quotas-loi-le-meur-ete-2026
18. Saint-Malo : quotas par 4 zones, 12,5 % des logements en intra-muros ; dispositif jugé efficace mais insuffisant par la ville. Verdict : fermé en centre, contingenté ailleurs. Sources : https://www.lechotouristique.com/article/locations-type-airbnb-saint-malo-experimente-les-quotas ; https://blog.qoridor.fr/article/saint-malo-face-a
19. Biarritz : quasiment plus aucune nouvelle autorisation ; autorisations non renouvelées par la mairie ; compensation exigée. Pays Basque (24 communes) également sous encadrement des loyers. Verdict : fermé. Sources : https://www.connexionfrance.com/news/the-french-tourist-cities-taking-a-stand-against-airbnb-style-lets/120320 ; https://www.monmeublesaisonnier.com/blog/location-courte-duree-france-regles-ville
20. La Rochelle : changement d'usage soumis à autorisation de l'agglomération depuis 2020 ; premières condamnations de propriétaires pour non-déclaration en janvier 2025. Verdict : contraint, contrôles actifs. Sources : https://www.larochelle.fr/fileadmin/mediatheque/1_Actualites/Espace_presse/Communique_de_presse_250108_-_LA_ROCHELLE_Meubles_de_tourisme_-_Premieres_condamnations_de_proprietaires_pour_non_declaration_de_changement_d_usage.pdf ; https://www.cpim.fr/airbnb-reglementation/la-rochelle/
21. Montpellier : 90 jours RP, changement d'usage requis pour les résidences secondaires. Strasbourg : 120 jours, changement d'usage requis. Lille : changement d'usage à vérifier localement, enregistrement obligatoire. Toulouse, Nantes, Rennes : enregistrement et changement d'usage selon règlement local, moins de compensation systématique (vérifier le service urbanisme avant toute offre). Sources : https://www.monmeublesaisonnier.com/blog/location-courte-duree-france-regles-ville ; https://www.cpim.fr/airbnb-reglementation/lille/
22. Zones permissives de fait : communes hors zone tendue et de moins de 200 000 habitants sans règlement de changement d'usage (littoral secondaire, moyenne montagne hors stations saturées, villes moyennes), avec deux risques à modéliser : THRS majorée jusqu'à 60 % (fait 10) et possibilité pour la commune d'instaurer quotas et changement d'usage à tout moment (fait 5). La croissance de l'offre 2025 y est forte : Le Mans +43 %, Annemasse +38 %, Bayonne +38 %. Source : https://airbtics.com/short-term-rental-market-report-2025-france

### 1.3 Comment les professionnels opèrent légalement malgré les restrictions

23. Bail mobilité (loi ELAN) : 1 à 10 mois, non renouvelable, locataire en études, formation, stage, mission ou mutation professionnelle ; pas de dépôt de garantie ; charges au forfait ; pas soumis au plafond 120/90 jours ni au changement d'usage ; loyer typiquement +10 à +20 % vs meublé classique. Risque : requalification en meublé de tourisme si les annonces, durées, échanges et déclarations révèlent un usage touristique (preuve du motif daté exigée ; la Cour de cassation applique l'exception strictement en 2026 ; amende civile jusqu'à 100 000 € par local). Sources : https://kohenavocats.fr/2026/04/29/bail-mobilite-airbnb-2026-paris-changement-usage-amende-recours/ ; https://www.monmeublesaisonnier.com/blog/bail-mobilite-airbnb ; https://www.cpim.fr/airbnb-reforme-2026-impact-investisseur/
24. Moyenne durée meublée (1 à 12 mois : expatriés, salariés en mission, étudiants, travaux) via bail meublé classique 1 an ou bail mobilité, diffusée sur Airbnb "séjours longs" (28 nuits et plus), Booking, Spotahome, Homelike : séjours de 7 jours et plus représentent déjà 43 % des réservations en France. Sources : https://www.welkeys.com/blog/conciergerie-airbnb-chiffres-cles-france ; https://www.monmeublesaisonnier.com/blog/airbnb-longue-duree-guide-proprietaire
25. Mix "résidence principale 90 jours + bail mobilité le reste de l'année" : légal uniquement si le bien est réellement la résidence principale de l'exploitant (au moins 8 mois d'occupation) ; inapplicable à un investisseur locatif pur.
26. Locaux commerciaux ou bureaux transformés en hébergement touristique : pas de changement d'usage (le local n'est pas un logement), mais changement de destination au titre du PLU (sous-destination "hébergement hôtelier et touristique") que la commune peut soumettre à autorisation depuis le 1er juillet 2021 ; Paris l'applique. Faisable dans les villes moyennes, à vérifier commune par commune ; attention aux normes ERP et à l'accessibilité. Sources : https://www.gererseul.com/avant-ma-location/comment-transformer-un-local-commercial-en-lieu-habitable/ ; https://hospitality-on.com/fr/airbnb-toujours-dans-le-collimateur-de-la-ville-de-paris
27. Acheter un bien déjà autorisé : les autorisations de changement d'usage avec compensation sont attachées au local (pérennes) et se revendent avec le bien ; les autorisations temporaires (Nice, 3 ans) ne sont ni renouvelables ni cessibles. Vérifier l'arrêté d'autorisation au compromis. Source : https://www.monmeublesaisonnier.com/blog/location-courte-duree-france-regles-ville
28. Classement meublé de tourisme (1 à 5 étoiles, environ 350 €) : conserve l'abattement micro-BIC 50 %, remplace la taxe de séjour proportionnelle (5 %) par un tarif fixe par étoile, et améliore la conversion. Source : https://www.cpim.fr/airbnb-reforme-2026-impact-investisseur/
29. Résidences secondaires en zones non tendues avec forte saisonnalité (littoral, montagne) : exploitation légale sans changement d'usage, mais rentabilité très dépendante de 10 à 14 semaines de haute saison (voir 2.2).

### 2.2 Saisonnalité

38. Août est le mois le plus fort, janvier le plus faible. Littoral (Nice, Biarritz, La Rochelle) : souvent plus de 80 % en été, parfois moins de 40 % hors saison ; PACA : 72 à 74 % en août, 30 à 41 % en décembre ; stations alpines : plus de 90 % pendant les vacances scolaires d'hiver ; Paris : 58 % (été) à 72 % (printemps) ; Lyon : 45 % (été) à 60 % (printemps) ; Marseille : 70 % (été) à 58 % (printemps). Sources : https://www.minut.com/fr/blog/taux-doccupation-airbnb-par-ville-analyse-complete ; https://modelesdebusinessplan.com/blogs/infos/marche-location-courte-duree-tendances
39. Conséquence pour le modèle : utiliser 12 coefficients mensuels, pas une moyenne annuelle ; les villes d'affaires (Paris, Lyon, Lille, Strasbourg) ont un profil inversé (creux en août) qui se combine bien avec le bail mobilité étudiant (septembre à juin).

### 2.3 Courte durée vs longue durée : le multiple réel

40. Exemple Paris, studio 30 m² : loyer longue durée médian 29,83 €/m² (CLAMEUR T4 2025) soit environ 895 €/mois, 10 700 €/an. En courte durée à 150 € ADR et 65 % d'occupation : 35 600 € brut/an, soit un multiple brut de 3,3x. Après Airbnb 15,5 % (5 500 €), conciergerie 20 % (7 100 €), ménages non refacturés et consommables (environ 2 000 €), énergie et internet (1 800 €), taxe de séjour collectée par la plateforme (neutre), assurance et CAPEX mobilier (1 200 €), THRS éventuelle : net d'exploitation environ 18 000 €, soit 1,7x le loyer longue durée, avant fiscalité moins favorable et risque réglementaire. Sources : https://clameur.fr/wp-content/uploads/2026/04/Dossier-presse-CLAMEUR-28-04-2026.pdf ; https://en.parisrental.com/blog/landlords-guide/airbnb-vs-long-term-furnished-rental-in-paris-2026-profitability-regulations-and-investor-strategy
41. Règle de décision des gestionnaires : la courte durée n'a de sens que si le revenu net d'exploitation est au moins 1,5x le loyer longue durée net, à cause du temps, de la volatilité, de l'usure et du risque réglementaire (hypothèse de praticien). Les écarts extrêmes existent surtout en zones touristiques peu denses (Ouessant : 33 620 € courte durée vs 7 030 € longue durée, écart 378 %). Source : https://airbtics.com/best-cities-for-airbnb-arbitrage-france
42. Le bail mobilité ou la moyenne durée se situe typiquement à 1,1x à 1,3x le loyer meublé classique avec 2 à 4 rotations par an (hypothèse cohérente avec le +10 à +20 % cité en fait 23).

### 2.4 Structure de coûts courte durée

43. Plateformes : Airbnb 15,5 % hôte (depuis le 13 octobre 2026, fait 11) ; Booking.com 15 à 18 % selon marché (hypothèse, grille standard) ; réservations directes 0 % plus coût du site et des paiements (environ 2 %). Source : https://www.lodgify.com/blog/fr/combien-vous-coute-reellement-airbnb/
44. Conciergerie : commission affichée 15 à 30 % du CA ; Île-de-France 2026 : basique 10 à 15 % (remise de clés, ménage sous-traité à part), standard 18 à 25 % (ménage et communication inclus), premium 25 à 35 % (gestion complète, pricing, home staging). Coût réel avec marges cachées : 24 à 38 % du CA. Sources : https://www.rentaplus.immo/blog/combien-coute-conciergerie-airbnb-2026/ ; https://eldorado-immobilier.com/conciergerie-airbnb-prix/
45. Marges cachées typiques : ménage facturé 80 € au voyageur pour un coût de 35 à 45 € ; linge facturé 8 à 15 € pour un coût de 4 à 6 € ; frais de mise en service 200 à 500 € ; option pricing dynamique +2 à 5 % ; majoration 10 à 25 % sur les interventions de maintenance. Exemple à 30 000 € de CA : conciergerie "20 %" coûte 9 200 € (30,6 %) contre 7 200 € pour une offre "24 % all-in". Sources : https://rentaplus.immo/blog/conciergerie-airbnb-commissions-marges-cachees/ ; https://rentaplus.immo/blog/comparatif-commission-conciergerie-airbnb/
46. Ménage et linge : coût de revient 35 à 45 € par rotation pour un studio/T2 (jusqu'à 60 à 90 € pour un T3 et plus), linge 4 à 6 € par rotation en blanchisserie industrielle ; refacturé au voyageur via "frais de ménage" mais désormais soumis à la commission Airbnb 15,5 %. Sources : fait 45 ; https://www.hostfully.com/fr/blog/frais-dhote-airbnb-explication-des-frais-de-155-a-la-charge-exclusive-de-lhote-2026/
47. VILLES_CD_FERMEES = {        # courte duree investisseur (residence secondaire) quasi impossible, faits 12 a 19

def strategie_courte_duree_possible(bien):
    # 1. Exclusions dures
    if bien.ville in VILLES_CD_FERMEES and not bien.autorisation_changement_usage_perenne:
        return False, "changement d'usage avec compensation : non rentable / impossible"
    if bien.copro_reglement_interdit_meuble_tourisme:              # fait 7
        return False, "reglement de copropriete interdit le meuble de tourisme"
    if bien.dpe in ("F", "G"):                                       # fait 6
        return False, "DPE F/G : autorisation refusee ; viser E minimum, D avant 2034"
    if bien.usage == "residence_secondaire_investisseur" and bien.commune_a_reglement_changement_usage \
            and not bien.autorisation_obtenue_ou_condition_suspensive:
        return False, "soumettre l'offre a une condition suspensive d'autorisation"
    # 2. Signaux de risque (penalites de score, pas d'exclusion)
    risque = 0
    if bien.ville in VILLES_CD_TRES_CONTRAINTES: risque += 2
    if bien.commune_zone_tendue: risque += 1                         # quotas possibles a tout moment, fait 5
    if bien.thrs_majoration >= 0.40: risque += 1                     # fait 10
    if bien.dpe == "E": risque += 1                                  # D exige en 2034, fait 6
    if bien.ville in VILLES_BOITES_A_CLES_INTERDITES and not bien.serrure_connectee_possible: risque += 1
    return True, {"score_risque_reglementaire": risque}

def strategie_retenue(bien, projections):
    cd_ok, info = strategie_courte_duree_possible(bien)
    ld_net = projections.longue_duree.revenu_net_annuel
    if cd_ok and projections.courte_duree.revenu_net_annuel >= 1.5 * ld_net \
            and info["score_risque_reglementaire"] <= 2:             # fait 41
        return "courte_duree"
    if bien.ville_universitaire_ou_affaires and projections.bail_mobilite.revenu_net_annuel >= 1.15 * ld_net:
        return "moyenne_duree_bail_mobilite"                         # fait 23
    if bien.nb_chambres_possibles >= 3 and projections.colocation.revenu_net_annuel >= 1.2 * ld_net:
        return "colocation"                                           # fait 76
    return "longue_duree_meublee" if bien.surface_m2 <= 45 else "longue_duree_nue"

def exclusions_longue_duree(bien):
    motifs = []
    if bien.dpe == "G": motifs.append("interdit a la location depuis 2025 : travaux obligatoires avant mise en location")   # fait 66
    if bien.dpe == "F" and bien.horizon_detention_annees > 1: motifs.append("interdit au 1/1/2028 : budgeter saut de classe")
    if bien.dpe == "E" and bien.horizon_detention_annees > 7: motifs.append("interdit au 1/1/2034")
    if bien.ville in TERRITOIRES_ENCADREMENT_LOYERS:
        motifs.append("plafonner le loyer au loyer de reference majore ; pas de complement si defaut")   # faits 60 a 63
    if bien.copro_taux_impayes > 0.25 or bien.copro_administrateur_provisoire: motifs.append("copropriete en difficulte")   # fait 88
    if bien.copro_charges_annuelles > 0.25 * bien.loyer_annuel_hc: motifs.append("ratio charges/loyer > 25 %")           # fait 89
    if bien.surface_m2 < 9 or bien.hauteur_sous_plafond_m < 2.20: motifs.append("non decent")
    return motifs

def score_opportunite_achat(bien, dvf):
    score = 0
    if bien.prix_m2_affiche <= 0.90 * dvf.mediane_m2_quartier_12m: score += 3   # fait 101
    if bien.jours_en_ligne > 100: score += 2                                      # fait 98
    if bien.nb_baisses_prix >= 1: score += 1
    for mot in ("succession", "divorce", "urgent", "travaux", "loue", "occupe"):   # fait 102
        if mot in bien.annonce_normalisee: score += 1
    if bien.dpe in ("F", "G") and bien.ville_avec_forte_demande: score += 1       # decote a capter si travaux chiffres, faits 67 et 93
    if bien.dpe_date < "2026-01-01" and bien.chauffage == "electrique": score += 1  # reclassement gratuit probable, fait 67
    marge_cible = MARGE_NEGOCIATION_PAR_VILLE.get(bien.ville, 0.05) + (0.05 if bien.jours_en_ligne > 100 else 0)
    return score, marge_cible
